This repository contains my coursework, laboratory exercises, programming activities, documentation, and data structures projects for CPE 010 - Data Structures and Algorithms.

## Objectives

- Implement searching and sorting algorithms in C++.
- Implement binary trees and graph representations and traversals.
- Evaluate correctness and time complexity.

## Coursework

**Course Intended Learning Outcome (CILO).** By the end of the course, I should be able to apply fundamental data structures, design efficient algorithms, analyze time and space complexity, and build C++ programs using good programming style and appropriate data organization.

| Term | CILO |
| :--- | :--- |
| **Prelims** | Apply C++ fundamentals, abstract data types, and dynamic memory allocation to implement linear data structures such as arrays, linked lists, stacks, and queues.
| **Midterms** | Design and implement searching and sorting algorithms, and apply binary trees and graphs to organize and traverse data efficiently. 
| **Finals** | Analyze time and space complexity and apply advanced algorithmic strategies, including parallel algorithms, to build efficient C++ solutions for engineering-related problems.
